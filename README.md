# Blockit

An open-source clone of [one sec](https://one-sec.app): adds a mindful pause before you open distracting apps.
iOS first (Shortcuts-based interception), built with Expo / React Native and developed entirely on Windows.

- Plan: [spec/PLAN.md](spec/PLAN.md)
- Manual QA on a real iPhone: [spec/MANUAL_QA.md](spec/MANUAL_QA.md)

## Develop (Windows)

```bash
npm install
npm run check        # typecheck + lint + unit tests
npx expo start       # Metro for the dev client on your iPhone (same Wi-Fi)
npx expo start --web # quick UI preview in the browser
```

## Get it on an iPhone without a Mac

1. Open the latest **ios-build** run in GitHub Actions → download the artifact:
   - `blockit-device-debug`: dev client (loads JS from Metro on your PC, hot reload)
   - `blockit-device-release`: standalone app
2. Install the `.ipa` with [Sideloadly](https://sideloadly.io) using your Apple ID.
3. On the iPhone: Settings → General → VPN & Device Management → trust your Apple ID; enable Developer Mode.
4. Free Apple ID signatures expire after 7 days, so re-sideload weekly.

`ios/` and `android/` are generated by `expo prebuild` (CNG) and are not committed.
