# Blockit

## Users
Людина, яка автоматично відкриває соцмережі й хоче час на усвідомлений вибір. Пауза має працювати без ручного налаштування автоматизацій.

## Product
iOS 16+, Expo 58, нативний Screen Time. Одна група застосунків та одне правило: пауза 20 с за замовчуванням; опційно намір або введення фрази. Системний вибір довільних застосунків замість фіксованого каталогу.

## Constraints
Family Controls entitlement, App Group та три розширення. Підписані профілі потрібні для всіх чотирьох bundle ID. Windows дозволяє перевірити JS та генерацію проєкту; компіляція Swift потребує macOS, поведінка Screen Time — iPhone. Немає надійного живого таймера в shield. Повернення блокування через DeviceActivity може затриматись. Сесія 15 хв + 5 с запасу до мінімального інтервалу моніторингу. Сайти та категорії не підтримуються; picker пояснює вибір окремих застосунків.

## Ethical stance
Доступ лише після згоди. Без облікового запису, сервера, тестової оплати, вигаданих показників заощадженого часу. Сповіщення запитуються окремо. Відмова не перекриває ручний перехід до Blockit. Можна відмовитись від відкриття та вимкнути захист.

## Success
Вибір → запуск застосунку → системний shield → пауза/завдання → доступ лише до обраного застосунку → повернення блокування без запущеного JS. Жоден довільний deep link не надає доступ. Приклад не змінює системне блокування.

## Open questions
Час повернення shield та доставка сповіщень мають бути перевірені на цільовому iPhone. Наявність дозволів Apple у поточному обліковому записі не перевірена.
